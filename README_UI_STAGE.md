# MY EXPO BAG TEST — 第1段階 UI改修（2026-11-10）

本ZIPは GitHub のテスト専用リポジトリ `sbcmt/myexpobag-test` の直下に展開する **全ファイル版** です。ZIPのままGitHubへアップロードしないでください。既存の同名ファイルは更新してください。

## 重要：Firestoreルールを先に更新

改修版を使う前に Firebase Console の **my-expo-bag-test → Firestore Database → ルール** で、本ZIPの `firestore.rules` に置き換えて「公開」してください。

古いルールのままでは新しい `variantAxes`, `releaseYear`, `reservationStock`, `imageData2` で保存拒否されます。絶対に本番 `my-expo-bag` のルールを変更しないでください。

## 新UI
- 商品登録・編集：基本情報／画像登録／抱き合わせ／予約販売／バリエーションの5タブ。
- 基本情報：通常価格、キャンペーン価格、バリエーションなし時のJAN、通常在庫、公開状態。
- 画像登録：最大2枚、保存済み画像の差替・削除、圧縮。Freeの1枚制限は有料化の段階で追加。画像一括登録ZIPは従来どおりメイン画像のみ。
- 予約販売：商品またはSKUごとに年月と上旬／中旬／下旬、予約在庫の入力。
- バリエーション：最大2軸・100種類まで自動生成。SKUごとにJAN、価格、通常在庫。軸の選択肢を後から並べ替えると同じSKUコードに別の組合せが割り当てられる可能性があるため、並び順を変える場合は保存前にJAN・在庫・予約を確認してください。
- 予約在庫は通常在庫とは分けて保存し、購入者向け在庫表示およびスタッフのQR受付時に予約品在庫を減算する。
- CSVの後方に年、予約在庫、SKU別JANなどの列を追加。以前の列順は維持。
- 管理画面のiOSホーム画面／Androidホーム画面／ファビコン：従来の `myexpobag_admin_icon_*` と `favicon-admin.*` を一切変更せず使用。購入者ページのアイコン/manifestリンクと専用画像ファイルは削除。テキストロゴを変更しない。

## 変更禁止

`assets/pop-*` の全ファイル、および A1 PDF用画像・`pop-download.js` は一切変更なし。`POP_IMAGES_SHA256.txt` で原本ハッシュを確認可能。

## 動作試験

Firestoreルール公開後、テスト専用アカウントで新規商品を登録し、2軸（カラー/サイズ）、SKU別JAN・予約年月／上旬中旬下旬／予約品在庫、画像1枚・2枚、予約/通常在庫の減算・取消による復元、CSV、プライスカード、POP、購入ページを確認してください。

本番環境には適用しないでください。Stripe / Free/Pro制限は次の段階です。
