MY EXPO BAG TEST — お客様ページ自動反映版（2026年11月11日）

【目的】
「お客様ページに反映」ボタンを廃止します。
商品を新規登録・編集・表示/非表示切替・CSV一括登録・画像一括登録・カテゴリ変更した後、
別の公開操作をしなくてもお客様ページに反映します。

【重要】
このZIPは、先ほどの「統合不具合修正版」の内容をすべて含んだ後継版です。
以前渡した統合修正版やUI復旧版を別にアップロードする必要はありません。
Firestoreルール（No.6公開済み）、productQuota、Stripe、Cloudflareは変更しません。
A1高解像度POP背景、管理画面のアイコン、ファビコン、テキストロゴには一切触れていません。

【GitHubへのアップロード】
テスト用： https://github.com/sbcmt/myexpobag-test
ZIPを必ず展開し、以下6ファイルだけをリポジトリのルートに登録してください。
既存のファイルは上書き、新規ファイルは追加します。
  1. products.js（上書き）
  2. products.html（上書き）
  3. catalog.js（上書き）
  4. catalog.html（上書き）
  5. public-catalog-safety.js（追加または同内容で上書き）
  6. customer-catalog-sync.js（新規）

【機能】
商品詳細で「この商品の全タブをまとめて保存」→ お客様ページ自動反映。
登録商品一覧で「この商品の変更を保存」→ 表示/非表示・価格・在庫を自動反映。
表示OFFで保存 → お客様ページから非表示。再度ONで保存 → 自動的に再表示。
CSV商品一括登録・画像ZIP登録・カテゴリ登録/削除 → 保存後に自動反映。
削除時 → 公開解除・削除・商品件数管理が連動し、文字入力確認は不要。
未処理注文やバナーリンク商品は従来どおり削除を禁止。
Freeの予約販売・組合せ商品・CSV登録・画像2枚目の制限を維持。

【失敗時】
保存は成功して公開同期のみ失敗した場合は、その旨をエラーとして表示。
アプリを次に開いた際、未反映情報の自動同期を再試行します。
再試行するだけの「手動公開ボタン」は置きません。

【導入後の簡単な確認】
1. テストアプリを Ctrl+Shift+R で更新（GitHub Pagesに反映されてから）。
2. 「お客様ページに反映」ボタンがなくなっている。
3. テスト商品を「表示する」で保存 → お客様ページに表示される。
4. 同じ商品の表示をOFFで保存 → お客様ページから消える。
5. 同じ商品をONで保存 → 再び表示される。
6. Freeで予約・組合せ・CSVの入力欄が無効になっている。
7. テスト商品の削除で文字入力を求められず、商品数管理countも減る。
