GitHub Pagesのテスト環境だけに導入してください。本番環境へ反映しないでください。

## 今回の実装
- 管理画面Free／Pro.バッジ。未設定ユーザーはFree。
- プラン情報は `planEntitlements/{uid}` をFirestoreで読み取る方式（クライアントから書き換え不可）。
- Free商品10点・画像1枚・予約、組合せ、CSV一括登録、ノベルティ、カラー、アクセントプライスカードなどをUIで制限。
- 予約・組合せの基本フィールド、2枚目画像、公開点数に対してFirestoreルールでも制限。

## テスト用Pro権限を付与する場合
Firestore Consoleで `planEntitlements/{UID}` にフィールド `plan` (string) `pro` / `status` (string) `tester` を管理者が手動登録。Freeに戻す際は文書を削除。**クライアントに編集機能を付けないこと。**
