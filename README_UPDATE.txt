MY EXPO BAG TEST UI改修 第2段階（3点） / 2026-11-10

このZIPはGitHubの sbcmt/myexpobag-test に既存の同名ファイルを上書きするための更新データです。

更新する4ファイル
  products.html
  products.js
  settings.html
  settings.js

【改修1：登録済み商品一覧】
・一覧を商品登録・編集欄より上に配置
・商品名／商品IDのキーワード検索
・カテゴリ、公開状態、予約販売、在庫切れの絞り込み
・各商品に価格、公開状態、在庫数、編集・削除を表示

【改修2：ブランド・販売設定】
・ブランドデザイン（カラー、バナー）／販促・割引（アプリ割引、ノベルティ）／購入・受渡し（購入後QR無効化）の3グループへ整理
・各グループを開閉できるようにし、カラーの選択状態とプレビューを見やすく改善
・既存のブランドカラープリセット、登録済み設定値、保存形式を維持

【改修3：保存・公開】
・商品登録・商品編集は管理側に保存。お客様ページへ自動公開しません。
・「お客様ページに反映」ボタンを押して公開
・公開済み／変更未反映／未公開の状態を表示
・カテゴリ変更、CSV登録、画像一括登録、商品削除も、必要な場合は別途「お客様ページに反映」を押してください。
・注意：今回変更したのは「商品・カテゴリ」の公開フローのみ。ブランド設定は従来どおり保存操作でお客様ページにも反映されます。

【維持するもの】
・商品登録の6タブと最新ノベルティの設定画面
・画像登録2枚対応、SKU別JAN・価格・予約販売
・既存のPOP背景画像やA1印刷設定（このZIPには一切含めていません）
・既存の管理画面アイコンとテキストロゴ（変更していません）
・購入者向けコード（変更していません）

【アップロード手順】
1. このZIPをPCで解凍する
2. GitHubのmyexpobag-testリポジトリで、4ファイルを上書きする
3. GitHub Pages反映後にCtrl+F5で再読込する
4. 商品登録→商品一覧表示→検索→商品編集→未反映表示→公開→公開済み表示を確認する
5. 設定画面の3グループの開閉とブランドカラーのプレビューを確認する

Firestoreルール更新は不要です（前回のテスト環境用ルールを使用）。
本番Firebase・本番GitHubにはアップロードしないでください。

【検証】
JavaScript構文確認、Playwrightブラウザでのローカル擬似データによる登録、検索、公開、変更の再通知、設定画面のグループ開閉、カラー選択を確認しました。
実際のテスト用Firebaseに接続した操作は未検証です。
