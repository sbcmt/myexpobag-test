MY EXPO BAG TEST — 商品削除確認UI / 組合せ参照の修正 (2026-11-10)

GitHub myexpobag-test のルートで以下の2ファイルを上書きしてください。
  - catalog.html
  - catalog.js

変更:
- 削除の文字入力を廃止。
- 「本当に削除しますか？削除は取り消せません。」と、「削除」「キャンセル」ボタンだけの確認画面へ変更。
- 他の商品が組合せ販売で参照していても、残る商品から該当の組合せ参照を自動で取り除いて削除可能に変更。
- 未処理注文がある商品を削除しない安全策は保持。

重要な制約:
MY BAGは購入者のブラウザのlocalStorageに保存されるため、ほかの端末のMY BAGに商品が入っているか、管理画面から判定できません。
したがって現在の版では、公開中商品の削除制限は解除していません。
公開中の商品は非表示設定→お客様ページに反映→削除の順に進めます。
「MY BAGに入っていない場合のみ公開中でも削除」の厳密な実現には、サーバー側のBAGデータ保管と在庫/公開情報の連動が必要です。

この修正版は前回の安全削除版を前提としています。
Firestoreルール・POP背景・アイコン・ロゴ・購入者側のファイルは変更していません。
