# MY EXPO BAG TEST｜商品登録UI更新（2026-11-10）

本番環境ではなく `sbcmt/myexpobag-test` テスト環境のみに適用します。

## 変更ファイル
- `products.html`：6タブ、名称・順序、不要説明文の削除、入力画面
- `products.js`：2軸SKU入力、個別価格、親／個別予約チェックと一括発売時期、保存／公開処理
- `firestore.rules`：商品データの `preorderAll` 属性追加に対応

## GitHubへの適用
1. 以前のテスト版から `products.html` と `products.js` をそれぞれ同じ場所（リポジトリのルート）へ上書きします。
2. GitHub Pagesで反映を確認し、強制再読み込みします。
3. Firebase Consoleでプロジェクト `my-expo-bag-test` が選択されていることを確認します。
4. Firestore Database > ルール に `firestore.rules` 全文を貼り付けて公開します。

※ GitHubのルートに `firestore.rules` を置くだけではFirebaseへは反映されません。
※ アプリの `firebase-config.js` は変更しません。
※ 本番の `my-expo-bag` にはアップロードもルール変更もしません。

## 機能
- タブ順：基本情報／画像／バリエーション／予約／組合せ商品／CSV一括登録。
- CSV商品登録・テンプレート・CSV出力はCSV一括登録のタブのみ。画像ZIP登録は画像タブに残す。
- バリエーション：項目名1・2、選択肢1・2、親商品ID_サブコード、価格（親価格を初期表示、変更可）、在庫、JAN、予約チェック。個別キャンペーン価格は各行の詳細欄。
- 親商品予約チェックON時は全SKUを予約対象とし、SKU個別で予約チェックを変更した場合は親チェックを自動解除。
- 予約タブ：商品名・種類の自動表示、発売予定を年／月／上旬・中旬・下旬の横一列、対象SKUへの一括適用、SKU別予約在庫。
- 商品画像はテストUIで最大2枚。プラン別のFree1枚／Pro2枚制限は有料化段階で追加。
- 現在の商品のないテスト環境で動作検証。実Firebase本番・テストDBへの自動変更なし。

## 素材の保護
