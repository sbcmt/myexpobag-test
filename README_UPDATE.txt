【修正内容】
・商品登録「組合せ商品」タブのノベルティチェックを削除。
・CSV一括登録の「ノベルティ対象(任意)」列は維持。1＝対象、0／空欄＝対象外。CSVからの指定は設定のチェック一覧に反映します。
・設定＞ノベルティ：登録済み商品名と商品IDの一覧＋複数チェックボックス。
・設定で対象の複数商品を保存（brandSettings/{slug}.novelty.productIds）。CSVからの登録も同じ対象ID一覧と連動します。
・以前の1商品ID方式は読込・受注履歴表示で互換を保持。
・購入者画面／QRスキャンで複数の対象商品を判定可能。
・設定が保存されない、商品がない場合は画面に案内表示。

【Firestoreルール】
変更不要。現行のルールは productIds と noveltyProductIds を許可しています。
参考用に firestore.rules を同梱（GitHubやFirebaseへは再設定不要）。

【保護対象】
・assets内のPOP背景画像には一切変更なし。
・既存の管理画面アイコン、テキストロゴにも変更なし。
・本番Firebaseは一切更新していません。テスト環境のみ更新してください。

【確認】
1. 設定 → ノベルティ → 指定商品を購入した方 → 商品名一覧に複数チェック。
2. 保存し、画面を再表示してチェックが保持されていること。
3. 購入者画面で対象商品を選ぶとノベルティ対象表示になること。
4. 管理者のQR読取結果にも対象表示が出ること。
5. 商品登録の「組合せ商品」タブにノベルティチェックがないこと。
6. CSV一括登録でノベルティ対象=1を指定すると、設定に対象チェックが表示されること。
